Mon carnet sur mon téléphone

Retrouvez votre carnet depuis une icône sur l’écran d’accueil.

  1. Ouvrez ce carnet dans Safari.
  2. Ouvrez le menu Partager, puis choisissez Sur l’écran d’accueil ou Ajouter à l’écran d’accueil.
  3. Si l’option est proposée, gardez Ouvrir comme app web activé, puis touchez Ajouter.

Sur Android : ouvrez le menu du navigateur (⋮), puis choisissez Installer l’application ou Ajouter à l’écran d’accueil.

Sur ordinateur : recherchez l’option d’installation dans la barre d’adresse ou le menu du navigateur. Si elle n’est pas proposée, le carnet reste accessible depuis ce lien.

Une connexion Internet reste nécessaire pour les exercices et l’enregistrement. À la première ouverture depuis l’icône, reconnectez-vous avec votre compte habituel si cela vous est demandé.
